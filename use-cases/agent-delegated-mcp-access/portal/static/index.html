Without a gateway, the agent itself has to:
  1. validate the SSO token on every request (signature, issuer, audience, scope) and work out who the caller is
  2. enforce policy: which users may use the agent, which MCP tools they may call, rate limits
  3. register a GitHub OAuth app and run the consent + callback for every user
  4. store and refresh each user’s GitHub token, and attach it as Authorization: Bearer on every MCP call
  5. keep an audit trail of whose authority was used, and support revocation

Not secure and not governed: every agent re-implements this on its own. It would hold each user’s long-lived, reusable GitHub token, with no per-request scoping, no central policy and no central audit or revocation. With the gateway, the agent never sees the token and each of these is enforced in one place.
